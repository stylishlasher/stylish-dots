# LazyVim cheatsheet   (q — закрыть)

## Выход / сохранение
:w сохранить   :q выйти   :wq / ZZ сохранить+выйти   :q! без сохранения
Space q q — выйти из всего

## Движение (Normal)
h j k l      ← ↓ ↑ →
w / b / e    слово вперёд / назад / до конца слова
0 / ^ / $    начало строки / первый символ / конец
gg / G       начало / конец файла
:42 или 42G  на строку 42
Ctrl+d / u   полэкрана вниз / вверх
%            перейти на парную скобку
f<c> / t<c>  к символу c в строке; ; и , — повтор
{ / }        абзац назад / вперёд

## Правка
i a I A o O  режимы вставки
x            удалить символ        dd удалить строку
yy           копировать строку     p / P вставить после / до
u / Ctrl+r   отмена / повтор
.            повторить последнее изменение
cw ciw ci" ci(   изменить слово / целое слово / в кавычках / в скобках
>> / <<      сдвиг строки
J            склеить строки
~            сменить регистр
gcc / gc     закомментировать строку / выделение

## Visual
v V Ctrl+v   символы / строки / блок
после выделения: d y c > <

## Поиск
/text  n N   искать, дальше / назад
*            искать слово под курсором
:%s/old/new/g   заменить везде (добавь c для подтверждения)
Space s g    grep по проекту      Space /  то же
Space Space  найти файл           Space s k  поиск по хоткеям

## Окна и вкладки
Ctrl+h/j/k/l   переход между окнами
Space -  / |   split горизонтально / вертикально
Space w d      закрыть окно
Shift+h / l    предыдущий / следующий буфер
Space b d      закрыть буфер
Space e        проводник
Space ,        список буферов

## Код (LSP)
K            документация       gd  к определению
gr           ссылки             gI  реализация
Space c a    code action        Space c r  переименовать
Space c f    форматировать      ]d [d  следующая/пред. ошибка
Space x x    список диагностики

## Git
Space g g    lazygit            Space g b  blame строки

## Прочее
Space u ...  переключатели (wrap, numbers, ...)
:Lazy  :Mason  :LazyExtras  :checkhealth
