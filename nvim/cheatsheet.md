# stylish-lazyvim — cheatsheet

`q` / `<Esc>` закрыть это окно · `F1` или `<leader>H` открыть

## База
- `:w` сохранить · `:q` выйти · `:wq` сохранить+выйти
- `<Space>qq` выйти из Neovim
- `u` / `<C-r>` отмена / повтор
- `.` повторить последнее действие

## Движение
- `h j k l` ← ↓ ↑ →
- `w b e` по словам · `0 $` начало/конец строки
- `gg G` начало/конец файла · `{ }` абзац
- `<C-d>/<C-u>` полэкрана · `%` парная скобка

## Поиск / файлы (LazyVim/Snacks)
- `<Space><Space>` найти файл
- `<Space>/` grep по проекту
- `<Space>,` буферы · `<Space>e` файловый проводник
- `<Space>sk` поиск по хоткеям
- `n N` след./пред. совпадение · `<Esc>` убрать подсветку

## Редактирование
- `gcc` коммент строки · `gc` коммент выделения
- `> <` отступ (в visual сохраняет выделение)
- `<A-j>/<A-k>` двигать строки/выделение
- `gsa` добавить surround · `gsd` удалить · `gsr` заменить

## Окна / буферы
- `<C-h/j/k/l>` переход между окнами
- `<Space>-` / `<Space>|` split
- `<S-h>/<S-l>` пред./след. буфер · `<Space>bd` закрыть буфер

## LSP / код
- `K` документация · `gd` определение · `gr` ссылки
- `<Space>ca` code action · `<Space>cr` rename
- `<Space>cf` форматировать · `]d [d` диагностика
- `<Space>xx` список проблем (Trouble)

## Git
- `<Space>gg` Lazygit
- `<Space>gb` blame строки · `]h [h` hunks

## Прочее
- `<Space>l` Lazy (плагины) · `<Space>cm` Mason
- `<Space>un` выключить номера · `<Space>uw` wrap
- `:Cheat` эта шпаргалка
