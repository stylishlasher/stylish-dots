# Fastfetch presets

Presets installed by multitool:

- `default` - balanced fastfetch-like default.
- `mine` - user's compact setup (small logo, short keys).
- `micro` - minimal 4-line output.
- `stylish` - icon-rich visual preset.
- `universal` - broad info preset for most systems.

Install manually:

```bash
mkdir -p ~/.config/fastfetch
cp config/fastfetch/presets/mine.jsonc ~/.config/fastfetch/config.jsonc
```
