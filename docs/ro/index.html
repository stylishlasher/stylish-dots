Fetch-uri 3D

Fetch-urile C abandonate, rescrise în Rust.

Vechile surse C, instabile, sunt păstrate ca legacy, dar binarele funcționale se construiesc acum din config/fetches/stylish-fetches. Fără pornire automată în terminal și fără mod pinned — doar o comandă explicită.

--rotate horizontal --rotate vertical --rotate random
keyfetchcheie 3D
treefetchpom odorizant
tomatofetchroșie 3D
stoolfetchtaburet 3D
skeletonfetchcheie schelet
manualrulare doar prin comandă
ExempleRust
keyfetch --rotate random
 treefetch --rotate horizontal --accent green
 tomatofetch --rotate vertical --rainbow
 stoolfetch --height 18 --no-info
 skeletonfetch --rotate random --color gold

Preseturi fastfetch

Cinci preseturi pentru toate stările.

Instalatorul poate plasa un preset în ~/.config/fastfetch/config.jsonc și face o copie de siguranță a fișierului vechi.

default

Un set echilibrat de module implicite.

mine

Stilul tău compact: logo mic, chei scurte, zgomot vizual minim.

micro

Ieșire ultra-scurtă: 4 linii, doar esențialul.

stylish

Icone Nerd Font, accent pe aspect.

universal

O gamă largă de informații pentru majoritatea sistemelor.

Instalarea unui presetmultitool
bash arch_multitool.sh
# Instalare software → Fetch-uri → Preseturi fastfetch
# alege: default / mine / micro / stylish / universal

Instalare

Pornire rapidă.

Arch Linux

Printr-o singură comandă:

curl -fsSL https://raw.githubusercontent.com/stylishlasher/stylish-dots/main/arch_multitool.sh | bash

Debian / Ubuntu

Varianta adaptată:

curl -fsSL https://raw.githubusercontent.com/stylishlasher/stylish-dots/main/arch_multitool_debian.sh | bash

Doar configul end-4

git clone https://github.com/stylishlasher/stylish-dots.git
cd stylish-dots
bash config/end4/install.sh

Fetch-uri 3D în Rust

cd stylish-dots/config/fetches/stylish-fetches
cargo build --release
install -m755 target/release/*fetch ~/.local/bin/
Important: Cheile API nu sunt stocate în depozit. Cheile AI pentru illogical-impulse sunt în keyring. Fetch-urile 3D se rulează manual și nu pornesc la deschiderea terminalului. Multitoolul este un GUI/meniu; acțiunile sunt executate de modulele din modules/.
