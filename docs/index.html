Профили

Три пути, один репозиторий.

Мультитул не навязывает один стек — выбираешь профиль и то, что реально нужно.

end-4 / illogical-impulse

Мои оверрайды поверх end-4/dots-hyprland: Hyprland custom, Quickshell config.json, бинды Print, курсор Bibata, GTK/env. API-ключи не в репо — в keyring.

  • top bar always, bottom dock hover
  • ru layout, 180Hz, NVIDIA env
  • backup before apply

serpantinum

Внешний установщик Serpantinum через мультитул. Для тех, кто хочет полноценное окружение и пресеты отдельно.

  • установка через install.serpantinum.dev
  • пресеты из themes/
  • hypr kb layout patch

stylish-dots

Мои дотсы из репо: fish, nvim пресет по выбору, end-4 конфиг. Удобно, когда нужно быстро поднять своё окружение.

  • fish + starship + aliases
  • nvim preset chooser
  • end-4 config optional

Установка

Быстрый старт.

Мультитул

Интерактивное меню: профиль dotfiles, nvim пресет, зависимости, применение конфигов.

git clone https://github.com/stylishlasher/stylish-dots.git
cd stylish-dots
bash arch_multitool.sh

Только end-4 конфиг

Применить мой текущий конфиг поверх уже установленного dots-hyprland.

cd stylish-dots
bash config/end4/install.sh
Важно: API-ключи не хранятся в репозитории. AI-ключи для illogical-impulse добавляются через UI и сохраняются в keyring. Кастомные 3D-фетчи помечены как UNSTABLE/BETA, kind of abandoned и вынесены в config/fetches/unstable/.
