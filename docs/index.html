end-4 / illogical-impulse

Мои оверрайды поверх end-4/dots-hyprland: Hyprland custom, Quickshell config, бинды, курсор, env. Ключи — только в keyring.

stylish-dots

Мои дотсы: fish, nvim presets, end-4 config, fastfetch presets, Rust 3D fetches.

  • fish + aliases

  • fetches run by command only

3D Fetches

Мёртвые C-фетчи переписаны на Rust.

Старые нестабильные C-исходники сохранены как legacy, но рабочие бинарники теперь собираются из config/fetches/stylish-fetches. Никакого автозапуска в терминале и никакого pinned-режима — только явная команда.

--rotate horizontal --rotate vertical --rotate random
keyfetch3D ключ
treefetchёлочка-ароматизатор
tomatofetch3D помидор
stoolfetch3D табурет
skeletonfetchскелетный ключ
manualзапуск только по команде
ПримерыRust
keyfetch --rotate random
treefetch --rotate horizontal --accent green
tomatofetch --rotate vertical --rainbow
stoolfetch --height 18 --no-info
skeletonfetch --rotate random --color gold

Fastfetch presets

Пять пресетов под разные настроения.

Установщик умеет ставить пресет в ~/.config/fastfetch/config.jsonc и делает бэкап старого файла.

default

Сбалансированный стандартный набор модулей.

mine

Твой компактный стиль: small logo, короткие ключи, минимум визуального шума.

micro

Ультра-короткий вывод: 4 строки, только главное.

stylish

Иконки Nerd Font, акцент на внешний вид.

universal

Широкий набор инфы для большинства систем.

Установка пресетаmultitool
bash arch_multitool.sh
# Установка ПО → Фетчи → Fastfetch пресеты
# выбрать: default / mine / micro / stylish / universal

Установка

Быстрый старт.

Arch Linux

Одной командой:

curl -fsSL https://raw.githubusercontent.com/stylishlasher/stylish-dots/main/arch_multitool.sh | bash

Debian / Ubuntu

Адаптированная версия:

curl -fsSL https://raw.githubusercontent.com/stylishlasher/stylish-dots/main/arch_multitool_debian.sh | bash

Только end-4 конфиг

git clone https://github.com/stylishlasher/stylish-dots.git
cd stylish-dots
bash config/end4/install.sh

Rust 3D fetches

cd stylish-dots/config/fetches/stylish-fetches
cargo build --release
install -m755 target/release/*fetch ~/.local/bin/
Важно: API-ключи не хранятся в репозитории. AI-ключи для illogical-impulse — в keyring. 3D fetches запускаются вручную и не стартуют при открытии терминала. Мультитул — GUI/меню; действия выполняются модулями из modules/.
